# Overcomers Global Network - Admin Panel Guide

Welcome to the OGN Admin Panel! This guide will help you understand the core features available to you as an admin.

## Getting Started

### 1. Access Your Admin Dashboard
- Go to: `https://overcomersglobalnetwork.com/admin`
- Use your admin email and password to log in
- Your dashboard is your central hub for all admin activities

### 2. Your Role & Permissions
- **Master Admin**: Has access to all features, can manage other admins
- **Regular Admin**: Has access to specific features as assigned by the Master Admin
- Your permissions determine which sections you can see and use

---

## Core Admin Features

### 📊 Dashboard
Your dashboard shows key metrics and quick access to your assigned areas:
- **Total Donations**: Live donation totals from Stripe
- **Discipleship Enrollments**: People who've enrolled in discipleship programs
- **1-on-1 Bookings**: Prophet Joshua session requests
- **Recent Donations** (Master Admin only): Latest donation details

### 👥 People Management
This is your primary tool for managing church contacts and relationships.

#### What You Can Do:
- **Add New People**: Record visitors, members, and contacts
- **Search & Filter**: Find people by name, email, phone, or tags
- **Assign People**: Assign contacts to yourself (Master Admin can assign to anyone)
- **Add Notes**: Keep communication records visible to all admins
- **Follow-Up Tracking**: Tag people who need follow-up and mark when completed

#### Best Practices:
- Add notes after every interaction (calls, meetings, emails)
- Use consistent tags (New Visitor, Member, Leader, Volunteer, etc.)
- Mark follow-ups as complete to keep the system current
- Check the "Needs Follow-Up" filter daily

#### Tags You Can Use:
- New Visitor, Member, Leader, Volunteer, First Timer
- Online, Needs Prayer, VIP, Youth, Mentor
- Create custom tags as needed

## Features Reserved for Master Admin

Some advanced features are only available to the Master Admin:
- **Managing Other Admins**: Adding/removing admins, setting permissions
- **Prophet Schedule**: Managing 1-on-1 session availability
- **Full Donation Details**: Access to complete Stripe donation history
- **System Settings**: Advanced configuration options

## Daily Workflow Recommendations

### Morning Routine (5-10 minutes)
1. Check your **Dashboard** for new enrollments and bookings
2. Review **People** filtered by "Needs Follow-Up"
3. Check **Prayer Requests** for urgent needs

### Weekly Tasks
1. Add all new visitors to **People** system
2. Update notes for people you've contacted
3. Review and complete any pending follow-ups
4. Check **Orders** if you manage resource distribution

### Communication Best Practices
- **Always add notes** after any interaction
- **Use consistent tags** for easy filtering
- **Assign people** to yourself when you take responsibility for follow-up
- **Mark follow-ups complete** to help other admins know the status

## Getting Help

### If You Need Assistance:
1. **Check this guide first** for common questions
2. **Contact the Master Admin** for permission changes or advanced features
3. **Use the Notes system** in People profiles to communicate with other admins

### Common Questions:
- **"I can't see a feature?"** - Check with Master Admin about permissions
- **"How do I assign someone?"** - Go to People → Select person → Assign to Myself
- **"Where are blog posts published?"** - They appear on the main website blog section
- **"How do event flyers work?"** - Upload them and they'll rotate on the homepage

## Security & Best Practices

- **Don't share** your admin login credentials
- **Use strong, unique passwords**
- **Report any issues** to the Master Admin immediately
